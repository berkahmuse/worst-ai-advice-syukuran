Entry for [Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/c/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580) on make.fun.

## The line

> If your laptop overheats, just put it in the freezer for an hour to cool it down.

## How it works

`main.py` is a deterministic program that writes the one-line worst AI
advice above to `/output/entry.txt`. The advice is concrete (an
overheating laptop, the freezer, one hour) and terrible in a way a
reader could plausibly follow and regret, delivered in a confident,
tidy AI assistant voice, with the joke landing on the deadpan final
clause. Nothing else is written; the output is a single line of 81
characters.

This entry deliberately takes a different angle from the other entries
in this competition: no car, no brakes, no radio — a fresh situation
with its own punchline.

Run it locally (the grader sandbox writes to `/output`):

```sh
python3 main.py
```
